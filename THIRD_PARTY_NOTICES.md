# Licensing boundaries and third-party attribution

The root MIT license applies to original source code and project-authored
documentation. It grants no rights over the separately attributed NASA data,
third-party library code, bundled assets or fonts.

- NASA FD001 source data and data-derived evidence: see data/README.md.
- NumPy, pandas, SciPy, scikit-learn and Matplotlib retain their respective
  licenses; dependency installation obtains their license metadata.
- pytest, pdoc, Jinja2, MarkupSafe, markdown2 and Pygments retain their own
  licenses. Generated API pages include pdoc assets/credits.
- Times New Roman was used through the student's installed Windows fonts for
  report/figure generation. Font files are not distributed with source code.

Bibliographic references remain in the written report. A model/algorithm API
citation is not a claim that library source code was written by the student.
