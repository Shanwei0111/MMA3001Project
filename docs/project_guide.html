Turbofan Remaining Useful Life Prediction

Chua Shanwei · 35393343 · MMA3001 Numerical Methods and Machine Learning

Estimate the remaining operating cycles of NASA C-MAPSS FD001 engines using age-only linear regression, multi-sensor linear regression, random forest and histogram gradient boosting. The code reproduces the student's current Assignment results with engine-level validation and quantitative performance analysis.

Environment and installation

The verified environment is CPython 3.14.5 on Windows 11 with NumPy 2.5.4, pandas 3.1.0, SciPy 1.18.1, scikit-learn 1.9.1, Matplotlib 3.11.2, threadpoolctl 3.7.0, pytest 9.1.1 and pdoc 16.0.0. All 30 dependency/build-tool versions are pinned in requirements-lock.txt. Python 3.14 is required.

Run these commands from the repository root:

git clone https://github.com/Shanwei0111/MMA3001Project.git
cd MMA3001Project
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m pip install --no-build-isolation --no-deps -e .
.venv\Scripts\Activate.ps1

If activation is restricted, use .venv\Scripts\python.exe in place of python. On Linux/macOS, the equivalent interpreter is .venv/bin/python; the recorded benchmark and exact environment verification were performed on Windows.

Data preparation

The three required raw files are train_FD001.txt, test_FD001.txt and RUL_FD001.txt. Use one of the following acquisition methods:

# Existing NASA folder supplied by the student
python -m rul_project data --data-source "../CMAPSSData"

# Or download the archive linked by NASA's official catalog
python -m rul_project data --download-data

The Moodle ZIP already includes the verified FD001 files. Run python -m rul_project data to check them. Public Git history excludes the raw files; data/manifest.json verifies exact bytes. Corrupt or changed files are rejected without overwrite. data/README.md explains the data source, original units and licensing boundary.

Reproduce the project

python -m pytest --junitxml=results/generated/pytest_results.xml
python -m rul_project all
python tools/verify_reproducibility.py
python tools/build_api_documentation.py --check

Allow several minutes for the complete workflow. The all command prepares labels, splits engines, trains all candidates, repeats grouped CV, evaluates official endpoints, bootstraps uncertainty, plots results and profiles cost. All fits use the same one-thread budget and seed 42. No windows, smoothing, feature scaling, engine weights or capped RUL targets are introduced.

Individual stages are available in this dependency order:

python -m rul_project prepare-data
python -m rul_project split-engines
python -m rul_project train-linear
python -m rul_project train-forest
python -m rul_project train-hgb
python -m rul_project evaluate-test
python -m rul_project analyse-uncertainty
python -m rul_project plot-results
python -m rul_project benchmark

results/generated/ holds the run's CSVs, figures and profiles. Use --output-dir results/generated/trial for a separate run; --data-dir overrides the raw source directory. The protected reference results cannot be chosen as an output directory. Earlier command spellings remain accepted for old notes.

Results and engineering comparison

Model Test MAE (cycles) Test RMSE (cycles) NASA-style score
Age-only linear 33.46 39.31 17239.68
Multi-sensor linear 26.40 31.83 9272.61
Random forest 19.38 25.82 5804.70
Histogram gradient boosting 18.93 26.18 7212.36

All models use the same 100 official test endpoints. RF was retained for RMSE and asymmetric-score performance; HGB is faster and smaller. Paired HGB-minus-RF error intervals include zero. The written report contains the equations, physical input units, complete validation, hardware benchmarks and interpretation of optimistic errors.

results/reference/ groups frozen metrics, predictions, uncertainty, performance and figures into separate subfolders. The original numbers are preserved. file_index.json connects original CSV names to their new locations. Verification compares both validation and test predictions, both CV tables and both bootstrap tables; timings are machine-specific.
